# Project Evidence

This directory contains supporting evidence for the NorthStar Azure Lab.

Evidence is organized around demonstrated Azure capabilities rather than unnecessary raw screenshots.

## Evidence Categories

### Infrastructure
- Resource group creation
- Virtual network configuration
- Subnet configuration
- Network Security Group configuration

### Compute
- Linux VM deployment
- VM networking
- Administrative access
- Network security

### Automation
- Azure CLI
- PowerShell
- Bash automation
- Bicep deployment definitions

### Governance
- Role-Based Access Control (RBAC)
- Azure Policy
- Resource governance

### Operations
- Log Analytics
- Azure Monitor
- Alerts
- Backup

### Troubleshooting
- Azure Load Balancer health investigation
- Effective route analysis
- NSG rule evaluation
- Root-cause identification
- Remediation
- HTTP connectivity verification

## Evidence Philosophy

The purpose of this repository is to demonstrate Azure administration skills through configuration, automation, troubleshooting, and technical documentation.

Evidence is included only where it helps demonstrate a specific technical capability.

## Security

No credentials, secrets, tokens, subscription IDs, or unnecessary public infrastructure information should be committed to this repository.

Temporary lab infrastructure is documented conceptually rather than exposing sensitive deployment details.
